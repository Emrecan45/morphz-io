# Credits - morphz.io

The same credits are readable in the game, from the footer of the menu, in the seven languages the
game speaks.

## 🎨 Visuals

Every visual in the game is original work. No external 3D model, no imported texture and no sprite
is used, and no icon set or icon font is loaded.

### Fonts

Two open source variable fonts are self hosted inside the project, so nothing is downloaded at
runtime.

| Font | Use | Author | License |
|--|--|--|--|
| [Fredoka](https://fonts.google.com/specimen/Fredoka) | Interface and logo, latin and latin extended | Milena Brandao, Hafontia | SIL Open Font License 1.1 |
| [Rubik](https://fonts.google.com/specimen/Rubik) | Cyrillic fallback | Hubert and Fischer, Meir Sadan, Cyreal | SIL Open Font License 1.1 |

### Icons

The sound, music, effects and language flag icons are original inline SVG drawn for this project.
The Discord glyph is the official brand mark, used only to link to the community server.

## 🔊 Audio

The game has no sound effects. The only audio is one music loop, released into the public domain
under Creative Commons Zero. CC0 asks for nothing in return, the credit below is given out of
respect for the work.

| Track | Author | Source | License |
|--|--|--|--|
| Flowerbed Fields, menu and in game | Zane Little Music | [OpenGameArt](https://opengameart.org/content/flowerbed-fields-loop) | CC0 1.0 |

The track already loops on itself, and it is re encoded to stereo Vorbis and levelled to the same
loudness as the rest of the game. The file is only downloaded once the music is on, so a player who
mutes it from the menu never pays for it.
